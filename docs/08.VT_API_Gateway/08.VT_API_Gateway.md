## 버전 연동 모델 (문서 ↔ 제품 ↔ 작업 ↔ 인증)

의료기기 인증(IEC 62304 / ISO 13485) 대응 — 문서·제품·작업·증적의 버전을 일관 연동하고, 릴리스별로 baseline을 동결한다.

| 설계 문서 (PRD/ARD/HLD) | 문서 버전(v1.0, v2.0 …) + 개정 이력 | 각 문서가 **적용 제품 버전** 명시 |
| --- | --- | --- |
| 제품 버전 | ES 4자리 Major.Minor.Patch.Build (정규/비정규) | Jira fixVersion = `gw/M.m.p.b` |
| 작업 추적 | Jira ESIP Epic/Story (fixVersion) | 기획 게이트 산출물 = 본 문서 링크 |
| 승인 | 위임전결 (정규=품의 / 비정규=전결) | 문서 상태 Draft → Reviewed → Approved |
| 인증 증적 | 요구사항 ID(FR/NFR) ↔ 설계(ADR) ↔ 테스트 추적성 | 릴리스별 baseline 동결 |

Controlled document 원칙: Confluence page history = 변경 원장, 본문 개정 이력 = 통제 요약, '적용 제품 버전'으로 제품·Jira와 결속.
