# **Regions of operation**

Straumann® AXS is a cloud-based platform at the core of the Straumann® integrated digital ecosystem. It provides a modular, open, and secure environment, enabling convenient and seamless dental treatment workflows that deliver an elevated customer experience.

# **A few facts**

AXS is globally present in the four business regions (to be updated AXS portal urls of different envs)

- NAM = North America → Hosted on our US or Canadian servers
- LATAM = Latin America → Hosted on our US server
- EMEA = Europe Middle-East Africa → Hosted on our European Server
- APAC = Asia Pacific → Hosted in our Singapore Server

**info**

Based on the customers and business region(s) where you want to roll out the integration with AXS, you must use the respective AXS portals and APIs. This will be explained further.

We have two environments in Straumann@ AXS:

- Production (PRD) using this environment will generate real billable orders. This environment is built to for AXS users and can host real patient data.
- Pre-Production (PPR) you can use this to build and test your integration. This environment should not host any patient data.
