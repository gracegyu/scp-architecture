# AXS OpenAPI 스냅샷

Straumann AXS Developer Portal **API Explorer**에 공개된 OpenAPI 3.0 스펙 전체.

- 출처: [API Explorer](https://developer.axs.straumann.com/api) · 인덱스 `https://developer.axs.straumann.com/specs/index.json`
- 취득일: 2026-06-16
- 취급: Straumann 자료 — **Confidential**. 최신은 항상 포털 정본을 확인한다.

## 파일

| 파일 | API | 비고 |
|------|-----|------|
| [index.json](index.json) | 카탈로그 | 5개 스펙 목록 |
| [authentication.yml](authentication.yml) | Authentication | OAuth2 Client Credentials (Token Creation) |
| [orders.yml](orders.yml) | Orders | Lab Order 관리·검색·파일 |
