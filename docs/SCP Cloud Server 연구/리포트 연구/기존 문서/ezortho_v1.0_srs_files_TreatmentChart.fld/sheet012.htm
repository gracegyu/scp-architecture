Elements Attributes Description
ImageEdit   Image Edit Information
Initial   Rotation / Flip / Crop information applied in the Image Edit Dialog.
The initial image displayed in Viewer is the image to which all transforms in this section have been applied.
Each transform is applied in order, one at a time. Otherwise the result image might be different.
Transform   Transform Information. Each Transform is applied in order, one at a time. 
  Type Rotate / Scale / Translate
  X Moving distance along x axis, when Type is "Translate"
X coordinate of the center of rotation, when Type is "Rotate", but always the center of th object in practice
X coordinate of the center of scale, when Type is "Scale"
  Y Moving distance along x axis, when Type is "Translate"
Y coordinate of the center of rotation, when Type is "Rotate", but always the center of th object in practice
Y coordinate of the center of scale, when Type is "Scale"
  Angle Rotation angle(dg), when Type is "Rotate"
  XScale Scales the coordinate system horizontally, when Type is "Scale".
  YScale Scales the coordinate system vertically, when Type is "Scale".
Flip   Image flipping information
  Horizontal Whether the image is flipped horizontally
  Vertical Whether the image is flipped vertically
Crop   Crop information. Based on the Scene Coordinate system.
  X X coordinate of the left-top point of the cropped region
  Y Y coordinate of the left-top point of the cropped region
  Width Width of the cropped region
  Height Height of the cropped region
Windowing   The windowing value that was last applied.
Brightness   Brightness
Contrast   Contrast
ImageFiltering   The image filtering information that has been last applied.
Sharpen   Whether the sharpening image filter  has been applied
MaxSharpen   Whether the maximum sharpening image filter  has been applied
Inverse   Whether the inverse filtering has been applied
FilmEffect   Whether the sepia image filter has been applied
Transformations   The panning / zooming values that were last applied in Viewer by layout.
Layout   Layout Information
  Name Layout name
  LastViewSize The size of the view that the image was rendered most recently (EOTW-52)
Tab   Tab Information
  Name Tab name
Annotations   Annotations added by the user to the Image.
An individual item's position is specified in terms of its parent(image)'s coordinate system.
Length   Length Information
  LineStyle line style
  Stroke line color
  StrokeOpacity line opacity
  StrokeThickness line thickness
  Points Coordinate values of 2 points for a Length
  Text Length Value
MultiLength   MultiLength Information
  LineStyle line style
  Stroke line color
  StrokeOpacity line opacity
  StrokeThickness line thickness
  Points Coordinate values of more than 2 points for a MultiLength
  Text Length Value. The last one is for the total length.
Angle   Angle Information
  LineStyle line style
  Stroke line color
  StrokeOpacity line opacity
  StrokeThickness line thickness
  Points Coordinate values of 3 points for a Angle
  Text Angle Value
Memo   Memo Information
  LineStyle line style
  Stroke line color
  StrokeOpacity line opacity
  StrokeThickness line thickness
  Points Coordinate values for memo point
  Text Memo Content
FreeDraw   Free Draw Information
  LineStyle line style
  Stroke line color
  StrokeOpacity line opacity
  StrokeThickness line thickness
  Points Coordinate values of more than 2 points for a FreeDraw
Lines   Line Information
  LineStyle line style
  Stroke line color
  StrokeOpacity line opacity
  StrokeThickness line thickness
  Points Coordinate values of 2 points for a line
Ellipse   Ellipse Information
  LineStyle line style
StrokeThickness line thickness
Stroke line color
StrokeOpacity line opacity
Points Center point of ellpise
Radius Radius along the x-axis and y-axis
Rectangle   Rectangle Information
  Left X coordinate of the left-top point of the rectangle region
  Top Y coordinate of the left-top point of the rectangle region
  Width Width of the rectangle region
  Height Height of the rectangle region
  LineStyle line style
  StrokeThickness line thickness
  Stroke line color
  StrokeOpacity line opacity
ModelAnalysis   Model Analysis Information. Only for Model images.
Measurement   Measurements for Model Analysis
  Name Measurement Name
Position Location information of the measurement
Value The value entered by the user. If there is a user input value, replace the value calculated by the point picking with this value.
Landmarks   Tracing Information
An individual item's position is specified in terms of its parent(image)'s coordinate system.
  FromDAVIS True if it is from DAVIS Web, and false otherwise.
Will be used If the user wants the auto ceph tracing from DAVIS Web again.
Landmark   Cephalometric tracing information
  Name Landmark Name
  Type Landmark Type
"H" : hard tissue
"S" : soft tissue
"K" : skeleton outline
"P" : soft tissue outline
"C" : Constructed
  X The x coordinate value of the landmark point
  Y The y coordinate value of the landmark point
Simulation   Simulation Information
An individual item's position is specified in terms of its parent(image)'s coordinate system.
VTOSTO   VTOSTO Information
RealignedLandmarks   The landmarks realingned for VTOSTO simulation and their new location
WarpingHistory   Includes a history of landmark movements / rotations.
  ControlPoint The landmarks that moved or rotated
Text   Textbox to display values
  Left The x coordinate value of the textbox point
  Top The y coordinate value of the textbox point
  Width Width of the textbox
  Height Height of the textbox
  FontSize Font size (pt)
  Fill Color to fill background
  FillOpacity Opacity of the background
  LineStyle line style
  StrokeThickness line thickness
  Stroke line color
  StrokeOpacity line opacity
