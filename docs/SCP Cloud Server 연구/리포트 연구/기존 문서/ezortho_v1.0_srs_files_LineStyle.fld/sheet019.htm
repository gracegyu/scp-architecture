Element Attribute Description
PaperSetting   Paper Settings
  PaperSize Paper Size
  MarginTop Paper margin (Top)
  MarginBottom Paper margin (Bottom)
  MarginLeft Paper margin (Left)
  MarginRight Paper margin (Right)
  HeaderHeight Height of header region
  FooterHeight Height of footer region
Header   Header Setting Information
  FontFamily Font Family. Inherited to child elements.
  FontSize Font Size. Inherited to child elements.
  HorizontalAlighment The type of horizontal alignment (Left/Right/Center). Inherited to child elements.
  VerticalAlignment The type of vertical alignment (Top/Bottom/Center). Inherited to child elements.
Footer   Footer Setting Information
  FontFamily Font Family. Inherited to child elements.
  FontSize Font Size. Inherited to child elements.
  HorizontalAlighment The type of horizontal alignment (Left/Right/Center). Inherited to child elements.
  VerticalAlignment The type of vertical alignment (Top/Bottom/Center). Inherited to child elements.
PageContent   Page Content Setting Information
  FontFamily Font Family. Inherited to child elements.
  FontSize Font Size. Inherited to child elements.
  HorizontalAlighment The type of horizontal alignment (Left/Right/Center). Inherited to child elements.
  VerticalAlignment The type of vertical alignment (Top/Bottom/Center). Inherited to child elements.
Block   This is for managing controls by widget.
  Name Block's  Name
  Isvisible Whether all controls in the block are visible
  Left X coordinate of the left-top point in the Header/Footer/PageContent region
  Top Y coordinate of the left-top point in the Header/Footer/PageContent region
Lines   Line Information. To draw multiple lines with the same attributes, include multiple <Points>.
  LineStyle line style
  Stroke line color
  StrokeOpacity line opacity
  StrokeThickness line thickness
  Points Coordinate values of 2 points for a Line
Label   Label Information
  FontFamily Font Family
  FontSize Font Size
  FontStyle Font Style (Bold / Italic / Underline / Deleted). Use "|" for multiple attributes.  
  FontColor Font color
  TextBackColor Background color
  HorizontalAlignment The type of horizontal alignment (Left / Right / Center)
  VerticalAlignment The type of vertical alignment (Top / Bottom / Center)
  Content Contents
  ItemType Item Type. See "Item Type" tab
  Left X coordinate of the left-top point in the Header/Footer/PageContent region
  Top Y coordinate of the left-top point in the Header/Footer/PageContent region
  Width Width of label region
  Height Height of label region
TextBox   TextBox Information
  Name TextBox's Name
  Content Input text value
  Left The displayed value
  Top Y coordinate of the left-top point in the Header/Footer/PageContent region
  Width Width of TextBox
  Height Height of TextBox
RadioButton   Radio Button 정보
  GroupName Button의 Group ID
  Content The displayed value
  IsChecked Is checked or not
  Left X coordinate of the left-top point in the Header/Footer/PageContent region
  Top Y coordinate of the left-top point in the Header/Footer/PageContent region
  Width Width of RadioButton
  Height Height of RadioButton
CheckBox   CheckBox Information
  Content The displayed value
  IsChecked Is checked or not
  Left X coordinate of the left-top point in the Header/Footer/PageContent region
  Top Y coordinate of the left-top point in the Header/Footer/PageContent region
  Width Width of CheckBox
  Height Height of CheckBox
ComboBox   ComboBox Information
  Name ComboBox's Name
  Content The displayed value
  Left X coordinate of the left-top point in the Header/Footer/PageContent region
  Top Y coordinate of the left-top point in the Header/Footer/PageContent region
  Width Width of ComboBox
  Height Height of ComboBox
Image   Image Region Information
  Source Image file path
  Left X coordinate of the left-top point in the Header/Footer/PageContent region
  Top Y coordinate of the left-top point in the Header/Footer/PageContent region
  Width Width of Image region
  Height Height of Image region
