# 가상 머신 설치

- Linux terminal에서
- KVM 팩키지 설치
  - sudo apt updatesudo apt install -y qemu-kvm libvirt-daemon-system libvirt-clients bridge-utils virt-manager
- KVM 설치 확인
  - kvm --version # KVM 버전 확인sudo virsh list --all # libvirt 서비스 확인
- 현재 사용자 추가
  - sudo usermod -aG libvirt $(whoami)sudo usermod -aG kvm $(whoami)

## VirtIO 드라이버 준비

- https://fedorapeople.org/groups/virt/virtio-win/direct-downloads/virtio-win-pkg-scripts-input/virtio-win-0.1.266-1/
  - virtio-win-prewhql-0.1.zip 다운로드
- zip을 iso로 바꾸기
  - mkdir virtio-winunzip virtio-win-prewhql-\*.zip -d virtio-win
  - genisoimage -o virtio-win.iso -V "VirtIO Drivers" virtio-win
    - genisoimage 설치 필요함
      - sudo apt updatesudo apt install genisoimage -y
  - 확인
    - ls -l virtio-win.iso
  - 이동
    - sudo mv virtio-win.iso /var/lib/libvirt/images/

  - ![](https://vks.vatech.com/download/attachments/201472925/image-2024-11-19_14-53-55.png?version=1&modificationDate=1731995635230&api=v2)

  - "Add Hardware"에서 **CD-ROM** 장치를 추가한 뒤, VirtIO ISO를 선택한다.
  - ![](https://vks.vatech.com/download/attachments/201472925/image-2024-11-19_14-57-27.png?version=1&modificationDate=1731995847877&api=v2)
- Begin Installation을 눌러서 Windows 설치 시작
  - 제품키 없음 선택
  - Windows 10 pro 선택
  - 드라이버 로드
  - 설치할 드라이버 선택 > 찾아보기 > VirtIO CD 선택 후 AMD64폴터 선택 후 확인
    - ![](https://vks.vatech.com/download/attachments/201472925/image-2024-11-19_15-6-23.png?version=1&modificationDate=1731996383343&api=v2)
  - 5개 모두 설치한다.
    - **Red Hat VirtIO SCSI Controller (vioscsi.inf)**
      가상 디스크를 인식하기 위해 필요
      이 드라이버가 로드되면 디스크가 나타난다.
    - **Red Hat VirtIO Ethernet Adapter (netkvm.inf)**
      네트워크 연결을 설정하는 데 필요
      Windows 설치 후 네트워크가 동작하지 않으면 설치
    - VirtIO Balloon Driver (balloon.inf)
      메모리 사용 최적화를 지원
      필수는 아니지만 설치 후 성능 최적화에 유용
    - VirtIO Serial Driver (vioser.inf)
      VirtIO 기반의 시리얼 장치를 사용하는 데 필요
      일반적인 Windows 설치에는 불필요
    - QEMU FwCfg Device (fwcfg.inf)
      QEMU 특정 기능을 사용하는 드라이버로 일반적으로 불필요 → 그러나 Clipboard 공유하려면 필요
  - 드라이브 0 선택해서 설치
  - Windows 설치 중
    - 진행중 설정
    - 개인용 설정 선택
    - MS계정 → 오프라인 계정 선택
    - 제한된 환경 선택
