# 5. SonarQube, Dependency Track 구축을 위한 Network 설정

- TODO
    - 고정 IP 설정
    - DNS 관련
        - sqube.ewoosoft.com과 dtrack.ewoosoft.com을 모두 해당 IP에 연결한다.
- 임시로 localhost에서 강제로 sqube.ewoosoft.com과 dtrack.ewoosoft.com을 localhost로 연결하기
    - /etc/hosts 파일에 아래 내용 추가 (sudo로 실행)
        - 127.0.0.1 sqube.ewoosoft.com
        - 127.0.0.1 dtrack.ewoosoft.com
        - 127.0.0.1 sbom.ewoosoft.com (Jenkins)
    - 네트워크 매니저를 재시작한다
        - $ sudo systemctl restart NetworkManager
- Docker network 생성
    - 먼저, 모든 컨테이너가 동일한 네트워크에서 통신할 수 있도록 Docker 네트워크를 생성한다.
    - $ sudo docker network create webnet
        - 이제 SonarQube, Dependency Track에 모두 80port를 매핑할 수 있다.
        - PC를 rebooting해도 삭제되지 않는다.
