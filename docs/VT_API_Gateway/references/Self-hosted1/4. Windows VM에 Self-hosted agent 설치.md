# 4. Windows VM에 Self-hosted agent 설치

## Self-hosted agent 설치

- Windows VM에 Agent 폴더 생성
  - PowerShell은 관리자 권한으로 실행
  - mkdir C:\azure-agent1mkdir C:\azure-agent2mkdir C:\azure-agent3mkdir C:\azure-agent4
- Windows VM에서
  - Azure DevOps 웹 포털에서 **Organization Settings** → **Agent Pools**로 이동.
  - Self-hosted1 Agent Pool 선택 후, **New Agent**를 클릭.
  - OS 선택 화면에서 **Windows**를 선택하고, `Download agent` 버튼을 클릭하여 ZIP 파일을 다운로드
  - 다운로드한 ZIP 파일을 `C:\azure-agent1` ~ `C:\azure-agent4` 각 폴더에 복사한 후 압축 해제한다.
- Agent 구성
  - PowerShell은 관리자 권한으로 실행
  - cd C:\azure-agent1
  - .\config.cmd
  - 프롬프트에 따라 입력
  - Azure DevOps Server URL: https://dev.azure.com/ewoosoft
  - Authentication type: PAT
  - PAT: <YOUR_AZURE_DEVOPS_PAT>
  - Agent pool: Self-hosted1
  - Agent name: Agent Windows1
  - Work folder: _work
  - Run agent as service: Y
  - Enable SERVICE_SID_TYPE_UNRESTRICTED for agent service(press enter for N) > Enter
  - Enter User account to use for the service (press enter for NT AUTHORITY\NETWORK SERVICE): Enter
  - Enter whether to prevent service starting immediately after configuration is finished? (Y/N) (press enter for N) > Enter
  - Agent 등록 완료됨
