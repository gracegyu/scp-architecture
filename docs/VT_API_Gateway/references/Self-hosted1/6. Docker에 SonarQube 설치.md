# H2 DB에서 PostgreSQL로 마이그레이션하기

## 1. 기존 H2 기반 SonarQube 컨테이너 정리

```bash
# 기존 SonarQube 컨테이너 중지 및 삭제
$ sudo docker stop sonarqube
$ sudo docker rm sonarqube

# 기존 볼륨 백업 (필요한 경우)
$ sudo docker volume ls | grep sonarqube
# sonarqube_conf, sonarqube_data, sonarqube_logs, sonarqube_extensions

# 볼륨 삭제 (주의: 데이터가 삭제됩니다)
$ sudo docker volume rm sonarqube_conf sonarqube_data sonarqube_logs sonarqube_extensions
```

## 2. 기존 PostgreSQL에 SonarQube 데이터베이스 생성

기존에 `docker-compose.onpremise.yml`로 구축된 PostgreSQL을 활용합니다.

```bash
# PostgreSQL 컨테이너에 접속
$ sudo docker exec -it abc-wbs-postgres psql -U postgres

# SonarQube용 데이터베이스 생성
postgres=# CREATE DATABASE sonarqube;
postgres=# \q
```

## 3. Docker Compose로 PostgreSQL 연동 SonarQube 설치

**docker-compose-sonarqube.yml** 파일 생성:

```yaml
version: '3.8'

services:
  sonarqube:
    image: sonarqube:community
    container_name: sonarqube
    ports:
      - '9000:9000'
    environment:
      - SONAR_JDBC_URL=jdbc:postgresql://abc-wbs-postgres:5432/sonarqube
      - SONAR_JDBC_USERNAME=postgres
      - SONAR_JDBC_PASSWORD=postgres
    volumes:
      - sonarqube_conf:/opt/sonarqube/conf
      - sonarqube_logs:/opt/sonarqube/logs
      - sonarqube_extensions:/opt/sonarqube/extensions
    networks:
      - webnet
    restart: unless-stopped
    depends_on:
      - postgres-check

  # PostgreSQL 연결 확인용 헬스체크
  postgres-check:
    image: postgres:14
    command: ['pg_isready', '-h', 'abc-wbs-postgres', '-U', 'postgres']
    networks:
      - webnet
    depends_on:
      - postgres

  # 기존 PostgreSQL 참조 (실제로는 외부에서 실행 중)
  postgres:
    image: postgres:14
    container_name: abc-wbs-postgres
    external: true
    networks:
      - webnet

networks:
  webnet:
    external: true

volumes:
  sonarqube_conf:
  sonarqube_logs:
  sonarqube_extensions:
```

## 4. SonarQube 실행 및 확인

```bash
# Docker Compose로 SonarQube 실행
$ sudo docker-compose -f docker-compose-sonarqube.yml up -d

# 컨테이너 상태 확인
$ sudo docker ps

# 로그 확인
$ sudo docker logs sonarqube

# 데이터베이스 연결 확인
$ sudo docker exec -it abc-wbs-postgres psql -U postgres -d sonarqube -c "\dt"
```

## 5. 통합 Docker Compose 방식 (권장)

기존 `docker-compose.onpremise.yml`에 SonarQube와 Dependency Track을 통합하는 방식:

**docker-compose.integrated.yml**:

```yaml
version: '3.8'

services:
  postgres:
    image: postgres:14
    container_name: abc-wbs-postgres
    ports:
      - '5432:5432'
    environment:
      POSTGRES_USER: postgres
      POSTGRES_PASSWORD: postgres
      POSTGRES_DB: abc_wbs
    volumes:
      - postgres_data:/var/lib/postgresql/data
      - ./docker/postgres/init-integrated.sql:/docker-entrypoint-initdb.d/init-integrated.sql
    networks:
      - webnet
    healthcheck:
      test: ['CMD-SHELL', 'pg_isready -U postgres']
      interval: 10s
      timeout: 5s
      retries: 5
    restart: unless-stopped

  sonarqube:
    image: sonarqube:community
    container_name: sonarqube
    ports:
      - '9000:9000'
    environment:
      - SONAR_JDBC_URL=jdbc:postgresql://postgres:5432/sonarqube
      - SONAR_JDBC_USERNAME=postgres
      - SONAR_JDBC_PASSWORD=postgres
    volumes:
      - sonarqube_conf:/opt/sonarqube/conf
      - sonarqube_logs:/opt/sonarqube/logs
      - sonarqube_extensions:/opt/sonarqube/extensions
    networks:
      - webnet
    restart: unless-stopped
    depends_on:
      postgres:
        condition: service_healthy

  dependency-track:
    image: dependencytrack/apiserver
    container_name: dependency-track
    ports:
      - '8080:8080'
    environment:
      - ALPINE_DATABASE_MODE=external
      - ALPINE_DATABASE_URL=jdbc:postgresql://postgres:5432/dependencytrack
      - ALPINE_DATABASE_DRIVER=org.postgresql.Driver
      - ALPINE_DATABASE_USERNAME=postgres
      - ALPINE_DATABASE_PASSWORD=postgres
    volumes:
      - dependency-track_data:/data
    networks:
      - webnet
    restart: unless-stopped
    depends_on:
      postgres:
        condition: service_healthy

networks:
  webnet:
    external: true

volumes:
  postgres_data:
  sonarqube_conf:
  sonarqube_logs:
  sonarqube_extensions:
  dependency-track_data:
```

**docker/postgres/init-integrated.sql** 파일 생성:

```sql
-- SonarQube 데이터베이스 생성
CREATE DATABASE sonarqube;

-- Dependency Track 데이터베이스 생성
CREATE DATABASE dependencytrack;

-- 기존 abc_wbs 데이터베이스는 유지됨
```

## 6. 접속 및 초기 설정

```bash
# 서비스 실행
$ sudo docker-compose -f docker-compose.integrated.yml up -d

# SonarQube 접속: http://sqube.ewoosoft.com:9000
# 초기 계정: admin/admin → Ewoosoft1!@# 로 변경

# Dependency Track 접속: http://dtrack.ewoosoft.com:8080
# 초기 계정: admin/admin → admin/Ewoosoft1!@# 로 변경
```
