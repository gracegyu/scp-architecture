# 9. SonarQube, Dependency Track, Jenkins 을 80 port연결하기

# Reverse proxy를 이용하는 방법

- DNS 설정을 먼저 진행한다.
    - 5. SonarQube, Dependency Track 구축을 위한 Network 설정
- Docker network 생성
    - 먼저, 모든 컨테이너가 동일한 네트워크에서 통신할 수 있도록 Docker 네트워크를 생성한다.
    
    ```bash
    $ sudo docker network create webnet
    ```
    
    - 이제 컨테이너 이름으로 접속할 수 있다.
- SonarQube, Dependency track, Jenkins 실행한다.
    - 6. Docker에 SonarQube 설치
    - 7. Docker에 Dependency Track 설치
    - 8. Jenkins 설치하기 (SBOM,SonarQube)
- Nginx 설정
    - nginx 설정파일을 저장할 경로를 정한다.
        - 예) /home/raymond/Docker/nginx
    
    ```bash
    $ sudo mkdir -p /home/raymond/Docker/nginx/conf.d
    $ sudo nano /home/raymond/Docker/nginx/conf.d/default.conf
    ```
    
    **default.conf**
    
    ```
    server {
        listen 80;
        server_name dtrack.ewoosoft.com;
    
        location / {
            proxy_pass http://dependency-track:8080;
            proxy_set_header Host $host;
            proxy_set_header X-Real-IP $remote_addr;
            proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
            proxy_set_header X-Forwarded-Proto $scheme;
            client_max_body_size 50M;  # 필요에 따라 크기를 조절하세요.
        }
    }
    
    server {
        listen 80;
        server_name sqube.ewoosoft.com;
    
        location / {
            proxy_pass http://sonarqube:9000;
            proxy_set_header Host $host;
            proxy_set_header X-Real-IP $remote_addr;
            proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
            proxy_set_header X-Forwarded-Proto $scheme;
            client_max_body_size 50M;  # 필요에 따라 크기를 조절하세요.
        }
    }
    
    server {
        listen 80;
        server_name sbom.ewoosoft.com;
    
        location / {
            proxy_pass http://jenkins-server:8080;
            proxy_set_header Host $host;
            proxy_set_header X-Real-IP $remote_addr;
            proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
            proxy_set_header X-Forwarded-Proto $scheme;
            client_max_body_size 50M;  # 필요에 따라 크기를 조절하세요.
        }
    }
    
    server {
        listen 80;
        server_name wbs.ewoosoft.com;
    
        # 프론트엔드 정적 파일 서빙
        root /var/www/html/wbs;
        index index.html;
    
        # HTML 파일에 대한 캐시 비활성화
        location ~ \.html$ {
            add_header Cache-Control "no-cache, no-store, must-revalidate";
            add_header Pragma "no-cache";
            add_header Expires "0";
            try_files $uri $uri/ =404;
        }
    
        # JavaScript, CSS 파일 등에 대한 캐시 설정 최소화
        location ~ \.(js|css|svg|json)$ {
            add_header Cache-Control "no-cache";
            add_header Pragma "no-cache";
            expires -1;
            try_files $uri $uri/ =404;
        }
    
        location / {
            add_header Cache-Control "no-cache, no-store, must-revalidate";
            add_header Pragma "no-cache";
            add_header Expires "0";
            try_files $uri $uri/ /index.html;
        }
    
        # 업로드 파일 서빙 설정 (기존 그대로 유지)
        location /uploads/ {
            alias /data/abc-wbs/uploads/;
            add_header Cache-Control "public, max-age=31536000";
            expires max;
            try_files $uri $uri/ =404;
        }
    }
    ```
    
    - /home/raymond/Docker/nginx/conf.d/default.conf 파일은 누구나 읽을 수 있는 권한이 있어야 한다.
        - rw-r--r-- 1 root root 798 Jun 28 08:52 default.conf
- Nginx Docker 컨테이너 실행
    
    ```bash
    $ sudo docker run -d --name nginx-proxy \
        --network webnet \
        --restart unless-stopped \
        -p 80:80 \
        -v /home/raymond/Docker/nginx/conf.d:/etc/nginx/conf.d \
        -v /var/www/html/wbs:/var/www/html/wbs \
        -v /data/abc-wbs/uploads:/data/abc-wbs/uploads \
        nginx
    ```
    
- conf.d 수정후 컨테이서 다시 올리기
    
    ```bash
    $ sudo docker stop nginx-proxy
    $ sudo docker rm nginx-proxy
    $ sudo docker run -d --name nginx-proxy \
        --network webnet \
        --restart unless-stopped \
        -p 80:80 \
        -v /home/raymond/Docker/nginx/conf.d:/etc/nginx/conf.d \
        -v /var/www/html/wbs:/var/www/html/wbs \
        -v /data/abc-wbs/uploads:/data/abc-wbs/uploads \
        nginx
    ```
