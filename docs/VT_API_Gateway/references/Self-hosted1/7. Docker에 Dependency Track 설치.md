# H2 DB에서 PostgreSQL로 마이그레이션하기

## 1. 기존 H2 기반 Dependency Track 컨테이너 정리

```bash
# 기존 Dependency Track 컨테이너 중지 및 삭제
$ sudo docker stop dependency-track
$ sudo docker rm dependency-track

# 기존 볼륨 백업 (필요한 경우)
$ sudo docker volume ls | grep dependency-track

# 볼륨 삭제 (주의: 데이터가 삭제됩니다)
$ sudo docker volume rm dependency-track
```

## 2. 기존 PostgreSQL에 Dependency Track 데이터베이스 생성

기존에 `docker-compose.onpremise.yml`로 구축된 PostgreSQL을 활용합니다.

```bash
# PostgreSQL 컨테이너에 접속
$ sudo docker exec -it abc-wbs-postgres psql -U postgres

# Dependency Track용 데이터베이스 생성
postgres=# CREATE DATABASE dependencytrack;
postgres=# \q
```

## 3. Docker Compose로 PostgreSQL 연동 Dependency Track 설치

**docker-compose-dependency-track.yml** 파일 생성:

```yaml
version: '3.8'

services:
  dependency-track:
    image: dependencytrack/apiserver
    container_name: dependency-track
    ports:
      - '8080:8080'
    environment:
      - ALPINE_DATABASE_MODE=external
      - ALPINE_DATABASE_URL=jdbc:postgresql://abc-wbs-postgres:5432/dependencytrack
      - ALPINE_DATABASE_DRIVER=org.postgresql.Driver
      - ALPINE_DATABASE_USERNAME=postgres
      - ALPINE_DATABASE_PASSWORD=postgres
      - ALPINE_DATABASE_POOL_ENABLED=true
      - ALPINE_DATABASE_POOL_MAX_SIZE=20
      - ALPINE_DATABASE_POOL_MIN_IDLE=10
    volumes:
      - dependency-track_data:/data
    networks:
      - webnet
    restart: unless-stopped
    depends_on:
      - postgres-check

  # PostgreSQL 연결 확인용 헬스체크
  postgres-check:
    image: postgres:14
    command: ['pg_isready', '-h', 'abc-wbs-postgres', '-U', 'postgres']
    networks:
      - webnet
    depends_on:
      - postgres

  # 기존 PostgreSQL 참조 (실제로는 외부에서 실행 중)
  postgres:
    image: postgres:14
    container_name: abc-wbs-postgres
    external: true
    networks:
      - webnet

networks:
  webnet:
    external: true

volumes:
  dependency-track_data:
```

## 4. Dependency Track 실행 및 확인

```bash
# Docker Compose로 Dependency Track 실행
$ sudo docker-compose -f docker-compose-dependency-track.yml up -d

# 컨테이너 상태 확인
$ sudo docker ps

# 로그 확인 (초기 설정에 시간이 걸릴 수 있음)
$ sudo docker logs -f dependency-track

# 데이터베이스 연결 확인
$ sudo docker exec -it abc-wbs-postgres psql -U postgres -d dependencytrack -c "\dt"
```

## 7. 취약점 DB 업데이트 설정 (PostgreSQL 환경)

PostgreSQL 연동 후에는 컨테이너 내부 설정 파일 수정이 아닌 환경 변수로 설정합니다:

```yaml
# docker-compose 파일에서 환경 변수로 설정
environment:
  - ALPINE_DATABASE_MODE=external
  - ALPINE_DATABASE_URL=jdbc:postgresql://postgres:5432/dependencytrack
  - ALPINE_DATABASE_DRIVER=org.postgresql.Driver
  - ALPINE_DATABASE_USERNAME=postgres
  - ALPINE_DATABASE_PASSWORD=postgres
  # 취약점 DB 업데이트 주기 설정
  - ALPINE_WORKER_THREADS=0
  - ALPINE_WORKER_THREAD_MULTIPLIER=4
```

또는 컨테이너 실행 후 설정:

```bash
# 컨테이너 내부에서 설정 파일 수정
$ sudo docker exec -it dependency-track /bin/sh
$ cd /opt/owasp/dependency-track
$ vi application.properties

# 설정 후 컨테이너 재시작
$ sudo docker restart dependency-track
```
