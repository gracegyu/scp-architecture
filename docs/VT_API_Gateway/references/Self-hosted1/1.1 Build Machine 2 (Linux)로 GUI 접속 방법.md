    - VNC 서버 시작 스크립트 생성
        - mkdir -p ~/.vnc
            
            cat > ~/.vnc/xstartup << EOF
            
            #!/bin/sh
            
            unset SESSION_MANAGER
            
            unset DBUS_SESSION_BUS_ADDRESS
            
            export XDG_SESSION_TYPE=x11
            
            export DISPLAY=:4
            
            export GNOME_SHELL_SESSION_MODE=ubuntu
            
            export XDG_CURRENT_DESKTOP=ubuntu:GNOME
            
            # 화면 잠금 비활성화
            
            gsettings set org.gnome.desktop.lockdown disable-lock-screen true
            
            gsettings set org.gnome.desktop.screensaver lock-enabled false
            
            # 자동 로그인 설정
            
            dbus-launch --exit-with-session gnome-session
            
            EOF
            
            chmod +x ~/.vnc/xstartup

        - touch ~/.Xauthoritychmod 600 ~/.Xauthority
    - VNC 서버 시작

    - Linux Rebooting해도 자동 실행하게 설정하기
        - systemd 서비스 파일 생성
            - sudo vi /etc/systemd/system/vncserver-admin.service
                
                [Unit]
                
                Description=VNC Server for admin
                
                After=syslog.target network.target
                
                [Service]
                
                Type=forking
                
                User=admin
                
                Group=admin
                
                WorkingDirectory=/home/admin
                
                Environment=HOME=/home/admin
                
                Environment=USER=admin
                
                Environment=DISPLAY=:4
                
                Environment=XDG_SESSION_TYPE=x11
                
                Environment=GNOME_SHELL_SESSION_MODE=ubuntu
                
                Environment=XDG_RUNTIME_DIR=/run/user/1001
                
                ExecStartPre=/bin/sh -c '/usr/bin/vncserver -kill :4 > /dev/null 2>&1 || :'
                
                ExecStart=/usr/bin/vncserver :4 -geometry 1920x1080 -depth 24 -localhost no
                
                ExecStop=/usr/bin/vncserver -kill :4
                
                Restart=on-failure
                
                RestartSec=3
                
                [Install]
                
                WantedBy=multi-user.target

## 동시 접속 주의

TigerVNC 기본 설정은 **화면을 공유**한다. 여러 명이 붙으면 같은 화면을 보고 마우스·키보드가 섞인다. 작업 시간을 겹치지 않게 조율할 것.

# 문제 해결

## 증상 — `Authentication failure: No password configured for VNC Auth`

TCP 연결과 `RFB 003.008` 핸드셰이크까지는 되는데 **인증 단계에서만** 실패한다.

### 원인

TigerVNC 는 기동할 때 `~/.vnc/passwd` 를 **`/tmp/tigervnc.XXXXXX/passwd` 로 복사**해 두고 그 사본을 참조한다(프로세스 인자 `-PasswordFile` 로 확인 가능).

서버가 오래 떠 있으면 **`/tmp` 정리 작업이 그 디렉토리를 지운다.** 프로세스는 시작할 때의 경로를 계속 들고 있으므로, 포트는 열려 있고 데스크톱도 살아 있는데 인증만 깨진다.

2026-09-16 발생 시점의 서버 가동 시간은 **135일**이었다.

### 확인

```bash
# 서버가 참조하는 사본이 남아 있는지
pgrep -a Xtigervnc                      # -PasswordFile 경로 확인
ls -la /tmp/tigervnc.*/passwd           # 없으면 이 증상

# 원본은 보통 멀쩡하다 (8바이트 이진 파일 · 권한 600)
ls -la ~/.vnc/passwd                    # admin 계정에서
```

`~/.vnc/passwd` 를 `cat` 하면 깨진 문자가 나오는데 **정상이다.** 평문이 아니라 난독화된 8바이트 이진 파일이다.

### 조치 — 서비스 재시작

```bash
sudo systemctl restart vncserver-admin.service
sleep 3
systemctl is-active vncserver-admin.service
ls -la /tmp/tigervnc.*/passwd            # 새로 생겼는지
```

원본 `~/.vnc/passwd` 가 살아 있으면 사본이 다시 만들어진다.

⚠ **재시작하면 데스크톱 세션이 초기화된다.** 열어둔 창은 사라진다. **win10 VM 과 Jenkins 노드는 영향받지 않는다** — VM 은 libvirt 가 별도로 돌리므로 VNC 세션과 무관하다.

### 정상 복구 확인

암호 없이도 인증 협상 단계까지 확인할 수 있다.

```bash
python3 - <<'PY'
import socket, struct
s = socket.create_connection(('sbom.ewoosoft.com', 5904), timeout=10)
print("배너:", s.recv(12).decode(errors='replace').strip())
s.sendall(b"RFB 003.008\n")
cnt = s.recv(1)[0]
if cnt == 0:
    ln = struct.unpack(">I", s.recv(4))[0]
    print("거부:", s.recv(ln).decode(errors='replace'))
else:
    print("보안 타입:", list(s.recv(cnt)))   # 2 = VncAuth 가 있으면 정상
s.close()
PY
```

- 정상 — `보안 타입: [19, 2]` (19=VeNCrypt · 2=VncAuth)
- 고장 — `보안 타입 0개` + 거부 사유 문자열

## 재발 방지 (미적용 · TODO)

서비스 파일에서 암호 파일 경로를 고정하면 `/tmp` 정리와 무관해진다.

```
ExecStart=/usr/bin/vncserver :4 -geometry 1920x1080 -depth 24 -localhost no \
          -PasswordFile /home/admin/.vnc/passwd
```

수정 후 `sudo systemctl daemon-reload && sudo systemctl restart vncserver-admin.service`.
