# [C1] Clever One - EzServer - DAVIS Toolkit for Segmentation Version

Clever One과 함께 릴리즈 된 EzServer와 DAVIS Toolkit for Segmentation 버전 관리를 위한 페이지 입니다.

Clever One이 실행될 때, EzServer의 버전을 체크하고,

- EzServer 버전의 1번째 자리가 요구 버전보다 낮으면, 사용자에게 사용불가 알림을 띄우고 C1 강제 종료
- EzServer 버전의 2번째 자리가 요구 버전보다 낮으면, 사용자에게 일부 기능 사용 불가 알림을 띄우고 C1 실행
    - 1번째 자리가 같은 경우 2번째 자리 체크
- EzServer 버전의 3번째 자리는 체크 안함
