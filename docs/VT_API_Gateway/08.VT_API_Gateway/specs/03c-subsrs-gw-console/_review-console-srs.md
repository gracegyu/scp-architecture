>
> 리뷰라기보단 읽은 소감인데, 두 가지만 남겨 둡니다. **지금 뭘 바꿔야 한다는 얘기는 전혀 아니고**, 나중에 여유 있을 때 참고만 부탁드립니다.
>
> **1. 음차 표기**
> 일반 단어를 발음대로 옮긴 표기는 한글이 더 자연스러울 것 같다고 느낀 게 있었습니다. (예: 리전 컨텍스트→맥락, 스위칭→전환, 컬럼→열, 라이브→실시간, 데드락→교착 등) 기술 용어는 물론 그대로 두는 게 맞고요.
>
> **2. 문장 밀도**
> 한 문장에 정보와 괄호 부연이 많이 담겨서, 한 번에 읽어 내리기 조금 빽빽하게 느껴지는 구간이 있었습니다. 예로 §7.2 봉인 각주는 한 문장에 괄호 부연이 4개 들어 있는데:
>
> > 부모 `PATCH /admin/clinics/{id}`(clinic 표시필드=GW 로컬 스냅샷 직접수정·LMP 자체를 고치는 게 아님·LMP→GW 단방향)는 이미 구현돼 있으나, divergence 우려(device 자가 보정이 덮어씀)로 v1.0은 전 역할 X(권한 없음·서버 403)로 봉인하고 Console 미노출한다.
>
> 이런 문장을 나눠 쓰면 같은 내용이라도 조금 수월하게 읽히더라고요:
>
> > **봉인(sealed).** `PATCH /admin/clinics/{id}`는 clinic 표시필드를 GW 로컬 스냅샷에서 직접 고치는 API로, 이미 구현돼 있습니다. 다만 device 자가 보정이 이 값을 덮어써 불일치가 생길 수 있어, v1.0에서는 모든 역할에 막아 두고(서버 403) Console에 노출하지 않습니다. (LMP→GW 단방향 원칙, §7.2)
>
> 둘 다 내용 지적이 아니라 읽는 감각에 대한 얘기라, 편하게 넘기셔도 됩니다. 고생 많으셨습니다!

**판단:** 비차단. **#2(문장 밀도) 수용** — §7.2 봉인 각주 등 괄호 부연 겹친 문장 분할(다음 개정). **#1(음차)**: 리전 컨텍스트·컬럼·데드락·스위칭은 정착어/의미구분이라 **유지**([[loanword-transliteration-stance]]) · **`라이브`→`실시간`은 수용**(우리 문서 용례가 realtime). 답변은 이유 나열(사족) 빼고 간결하게. #2·라이브 반영 후 resolve.

**답변 초안:**

> 읽어 주시고 제안 주셔서 감사합니다.
>
> 문장 밀도(2번)는 전적으로 공감합니다. §7.2 봉인 각주처럼 괄호 부연이 겹친 구간을 주신 예시 방식대로 나눠 정리하겠습니다.
>
> 음차 표기(1번)는 리전 컨텍스트·컬럼·데드락·스위칭처럼 이미 정착됐거나 뜻이 구분되는 건 그대로 두겠습니다. 다만 라이브는 저희 문서에선 실시간 의미로 쓰여서 실시간으로 바꾸는 게 맞겠습니다.

## R2 — 정우혁(James) · thread 84008 · active

**코멘트(원문):**

> 향후 호환될 EzServer와 Client 버전(Clever One, EzDent-i, Clever Space, Clever Lab)도 어딘가(ex: SW 환경) 명시되면 좋을 것 같습니다.

**판단:** 타당. 다만 호환 클라이언트 버전의 **정본은 Console이 아니라 GW 호환성 매트릭스**(§7.7·`server-configuration.json`)이고, Console은 이를 **읽기전용 뷰어(FR-CON-28)** 로 노출한다. 실제 최소 버전 값은 각 제품 OnePager 확정 후 매트릭스에 채워진다. → 문서에서 그 관계가 잘 드러나도록 **매트릭스 뷰어 절 + §3.1.2 소프트웨어 환경에 "호환 클라 버전 정본=GW 매트릭스·Console은 뷰어" 한 줄**을 추가(additive·다음 개정). *(액션 아이템·아래.)*

**답변 초안:**

> 좋은 지적 감사합니다. 호환 클라이언트 버전(CleverOne·EzServer·CleverSpace 등)은 Console이 자체적으로 하드코딩하지 않고, GW가 공시하는 호환성 매트릭스(§7.7·`/.well-known/{env}/server-configuration.json`)가 정본입니다. Console은 이 매트릭스를 읽기전용으로 보여주는 뷰어(FR-CON-28)로 노출합니다.
>
> 실제 최소 버전 값은 각 제품 OnePager(CleverSpace·CleverOne·EzServer 등) 확정 뒤 매트릭스에 채워지고, EzDent-i·CleverLab처럼 아직 연동 전인 제품은 GW를 통하게 될 때 매트릭스 행으로 추가됩니다.
>
> 그 관계가 문서에서 바로 보이도록, 호환성 매트릭스 뷰어 절과 소프트웨어 환경(§3.1.2)에 "호환 클라이언트 버전의 정본은 GW 호환성 매트릭스이고 Console은 뷰어로 노출한다"는 문장을 명시하겠습니다.

**액션 아이템(다음 개정):** Console SRS 매트릭스 뷰어 절 + §3.1.2에 호환 버전 정본=GW 매트릭스·Console=뷰어 명시(additive).
