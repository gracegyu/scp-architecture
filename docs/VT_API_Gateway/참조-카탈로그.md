## 1. 워크스페이스 폴더 ↔ 로컬 경로 (`scp.code-workspace`)

Claude Code / VS Code가 여러 레포를 동시에 여는 multi-root 워크스페이스. **파일**: `~/Documents/Azure/scp.code-workspace`.

> **경로 주의**: 워크스페이스는 `../GitMunto/...`처럼 **상대 경로**로 `Azure/` 옆 `GitMunto/`를 참조한다. clone 위치가 다르면 폴더를 맞추거나 워크스페이스를 수정한다.
